# The settings find their break by name: with two own breaks (slots 1 and 2), TWO picked (the list: AMEN APACHE THINK
# ONE TWO), saved; slot 1 erased, so TWO moves up a place: after a reboot it is still TWO (by place it would be gone,
# the Amen). Then TWO erased as well: the Amen.
#   sh build.sh --host && app/build/host/amenity_host app/tests/breakname.txt build/breakname
#   (slot images: python -I app/tests/make_slots.py)
data app/tests/slot-one.bin 0x97000
data app/tests/slot-two.bin 0xA8000
reboot
wait 900
spin PRESET 4
wait 2500
expect brk 4
expect store_writes 1
data_erase 0x97000
reboot
wait 900
expect brk 3
shot 01-two-found.png
data_erase 0xA8000
reboot
wait 900
expect brk 0
# As a player found it on the device: both again, TWO picked and played, stopped; ONE deleted from the breaks page
# (its command): TWO stays chosen (not NO BREAK), and after a power-on it is still TWO
data app/tests/slot-one.bin 0x97000
data app/tests/slot-two.bin 0xA8000
reboot
wait 900
# (the settings still name TWO: back, it is found at once)
expect brk 4
tap PLAY
wait 600
tap PLAY
wait 300
delete 0
wait 100
expect brk 3
shot 02-two-after-delete.png
wait 2500
reboot
wait 900
expect brk 3
# the chosen one itself deleted: the Amen
delete 1
wait 100
expect brk 0
